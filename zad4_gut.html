1) Kiedy powstał JavaScript (podaj datę).

JavaScript został stworzony w 1995 roku przez firmę Netscape. Początkowo język nazywał się LiveScript.

2) Dlaczego jest to język skryptowy?

JavaScript jest językiem skryptowym, ponieważ pozwala tworzyć skrypty wykonywane przez środowisko uruchomieniowe, np. przeglądarkę. Skrypty mogą reagować na działania użytkownika i zmieniać zawartość strony.

3) Gdzie jest wykonywany JS (klient lub serwer)?

JavaScript może być wykonywany po stronie klienta, czyli w przeglądarce, oraz po stronie serwera, np. za pomocą środowiska Node.js.

4) Dlaczego JS to bezpieczne narzędzie?

JavaScript wykonywany w przeglądarce działa w środowisku ograniczającym jego dostęp do systemu użytkownika. Przeglądarka kontroluje między innymi dostęp do plików i innych zasobów komputera.

5) Czy jest to język obiektowy, jeśli tak to dlaczego?

Tak. JavaScript jest językiem wieloparadygmatowym i obsługuje programowanie obiektowe. W JavaScript można tworzyć obiekty oraz korzystać z właściwości i metod obiektów.

6) Wymień zalety JS:

Zaleta 1: Jest szybki i może być wykonywany bezpośrednio w przeglądarce.

Zaleta 2: Pozwala tworzyć interaktywne strony internetowe.

Zaleta 3: Jest stosunkowo łatwy do rozpoczęcia nauki i jest szeroko stosowany.

7) Framework to:

Framework to gotowy zestaw narzędzi, bibliotek i zasad ułatwiających tworzenie aplikacji.

8) Do aplikacji mobilnych można użyć Framework:

Do tworzenia aplikacji mobilnych można wykorzystać między innymi framework React Native.

9) Aplikacje responsywne to:

Aplikacje responsywne to takie aplikacje lub strony, które dostosowują swój wygląd i układ do rozmiaru ekranu urządzenia.

10) Przepisz linię kodu i wytłumacz, jak działa:

<input type="button" name="przycisk" value="Nowa Strona" onclick="WinOpen('')">

Jest to przycisk HTML. Po jego kliknięciu wykonywana jest funkcja JavaScript podana w atrybucie onclick.

11) Przepisz linię kodu i wytłumacz, jak działa:

window.open("obraz.html","okienko", "toolbar=no,directories=no,menubar=no,height=280,width=160,top=200,left=200");

Instrukcja window.open() otwiera nowe okno przeglądarki. Pierwszy parametr określa otwieraną stronę, drugi nazwę okna, a kolejne parametry określają wygląd, rozmiar i położenie okna.

toolbar=no – ukrywa pasek narzędzi.
directories=no – ukrywa elementy katalogów.
menubar=no – ukrywa pasek menu.
height=280 – wysokość okna.
width=160 – szerokość okna.
top=200 – odległość od górnej części ekranu.
left=200 – odległość od lewej części ekranu.

12) Opisz instrukcję window.close()

Instrukcja window.close() służy do zamknięcia okna przeglądarki lub okna otwartego przez JavaScript.
